# Bob Session Reports

**This folder is a graded submission deliverable.** IBM requires each team member to export their IBM Bob task session summaries here to prove Bob was a core build tool. Without it, the project is not eligible for judging.

## How to export (per the IBM guide)
For each task related to the submission:
1. In Bob IDE's chat interface, select **Tasks** to open the task list.
2. Select a task related to the project (use **All** to see tasks across workspaces).
3. Select the **task header** — a task session consumption summary appears.
4. **Screenshot** that summary.
5. Save the screenshot in this folder.

Repeat for every project-related task, across all team members' accounts.

## Naming suggestion
`<member>-<task>-<date>.png` — e.g. `aldo-gatekeeper-agent-2026-10-02.png`

## Before final submission
Confirm this folder contains a screenshot for every meaningful build task from every member.
